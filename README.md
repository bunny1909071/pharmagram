Pharmgram: an Instagram-style pharmacy learning app with AI-generated study posts and an AI tutor (Groq).

Add `GROQ_API_KEY` as a secret in Space settings. Optional variable: `GROQ_MODEL`.
Edit `static/content.json` to change the built-in posts.
